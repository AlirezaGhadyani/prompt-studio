OpenChamber extension

Prompt Studio

A searchable prompt library with fields and one-click insert into the chat composer. It never sends a message.

Open in OpenChamber

If the button does nothing, paste this into Settings → Extensions:

https://github.com/AlirezaGhadyani/prompt-studio.git
  1. Open Settings → Extensions in OpenChamber.
  2. Paste the Git URL and choose Add.
  3. No permission dialog appears; Prompt Studio asks for nothing.
  4. Open Prompt Studio from the right rail.

Requires OpenChamber 2.7 or newer, on web or desktop. Extensions do not run in the VS Code extension or on mobile. Updates are available in Settings → Extensions.
